# Student Profile System

## Project Title

Student Management System using React Components and Props

## Description

This project is a React-based Student Management System developed as part of React Day 1 Task 1.

The application demonstrates the basic concepts of React including:

- React components
- JSX
- JavaScript expressions
- Props
- Component reuse
- CSS styling

The application displays two student profiles using a reusable StudentProfile component.
